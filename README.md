# 🎮 First-Person Shooter (FPS) – Unity 3D

A 3D First-Person Shooter game developed using **Unity and C#**, exploring core FPS gameplay mechanics, player interactions, weapon systems, and immersive 3D environments.

- 🎮 First-person gameplay and player controls.
- 🔫 Weapon and shooting mechanics.
- 🎯 Player aiming and target interaction.
- 👾 Enemy interactions and combat mechanics.

## 🚀 Getting Started

### Prerequisites

- Unity Hub
- Compatible Unity Editor version
- Visual Studio or another C# IDE

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/unity-fps-game.git
```

**2. Open the project**

- Launch Unity Hub.
- Select Add Project from Disk.
- Select the cloned project folder.
- Open it using a compatible Unity Editor version.

**3. Run the game**

- Open the main gameplay scene from Assets.
- Press Play in the Unity Editor.
